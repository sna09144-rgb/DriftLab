# Описание экспериментальной процедуры

## Обозначения

Данные имеют два признака `X ∈ R²` и бинарную метку `Y ∈ {0,1}`. Положительный класс — 1. Интенсивность дрейфа `d ∈ [0,1]`.

## Генератор признаков

Для каждого объекта сначала генерируется латентная группа `z ∈ {0,1}` с равными вероятностями. Условно на `z`:
`X ~ Normal(μ_z, 0.85² I)`, где `μ_1=(1.0,0.8)`, `μ_0=(-1.0,-0.8)`.

## Covariate shift

Входные признаки преобразуются:
`X'_1 = X_1`, `X'_2 = X_2 + 1.5d`.
Метки затем генерируются одним условным механизмом:
`P(Y=1|X') = sigmoid(2.4 X'·w + 1.5 (x_1² − x_2²))`, `w=(cos(π/4), sin(π/4))`.
При изменении `d` меняется маргинальное распределение признаков, а параметр условного правила не меняется. Детерминированного сохранения метки исходного объекта нет: метка заново семплируется из фиксированного условного механизма для преобразованного X.

## Concept drift

Базовое распределение X не преобразуется. Вектор правила:
`w(d)=(cos(π/4 + dπ/2), sin(π/4 + dπ/2))`.
Тогда `P(Y=1|X)=sigmoid(2.4 X·w(d) + 1.5 (x_1² − x_2²))`. Угол меняется с интенсивностью и меняет условный механизм. При `d=0` угол совпадает с исходным.

В обоих сценариях шум метки добавляется отдельной вероятностью переворота `η`, указанной в параметрах.

## Разделение данных и контроль утечки

Чтобы сравнение можно было повторить, генератор получает отдельные детерминированные seed-последовательности для исходных данных, адаптации и теста. Тестовые объекты не участвуют в подгонке модели или выборе параметров. При фиксированных повторе и интенсивности каждая стратегия оценивается на одном тестовом наборе; для других уровней создаются отдельные, но воспроизводимые выборки.

## Сравниваемые варианты обучения

1. `baseline`: исходная модель обучена на исходной выборке.
2. `recent`: модель того же семейства обучена только на адаптационных данных.
3. `combined`: модель обучена на объединении исходных и адаптационных данных.

Объёмы данных отличаются и выводятся явно. В каждой стратегии StandardScaler обучается только на её тренировочных данных внутри sklearn Pipeline.

## Метрики

Матрица ошибок задаётся строками истинных классов [0,1] и столбцами предсказанных [0,1]. Specificity=`TN/(TN+FP)`. Balanced accuracy — среднее recall положительного и отрицательного классов. ROC-AUC рассчитывается по вероятности класса 1 и недоступна при единственном классе в тесте.

## Обработка вариативности результатов

Среднее и выборочное стандартное отклонение считаются по повторам для каждой комбинации дрейфа, интенсивности, стратегии и модели. При n<2 стандартное отклонение и интервал недоступны. Интервал `mean ± t(0.975; n−1) * SD/sqrt(n)` строится по распределению Стьюдента (при n=5 критическое значение 2.776, а не 1.96: z-интервал при n=5 покрывает лишь ≈88% вместо 95%). Интервал описывает вариативность результата между запусками генератора/обучения, не вариативность объектов внутри одного теста.

## Эталонный ориентир и сравнение пар

Oracle — классификатор, знающий истинное правило (`logit > 0`); его точность на том же тесте — верхняя граница для любой модели (шум меток <0.5 знак решения не меняет). Для сравнения стратегий считается парная разность метрики на одной тестовой выборке по повторам с t-интервалом; признак «интервал не содержит 0» описательный, поправка на множественные сравнения не вводится.

## Нелинейность правила

Если истинное правило линейно, логистическая регрессия специфицирована верно, и covariate shift ей почти не вредит (проверено: точность 0.859→0.858). Поэтому в правило добавлен квадратичный член: линейная модель становится приближением, и сдвиг P(X) меняет качество.

## Ограничения

Синтетическая постановка и логистическая регрессия не охватывают все реальные механизмы дрейфа. Covariate shift реализован с повторной стохастической разметкой фиксированным правилом. Это не доказательство строгого равенства `P(Y|X)` во всех возможных интерпретациях преобразования. Нет автоматического обнаружения дрейфа, настройки гиперпараметров или проверки статистической значимости различий.
