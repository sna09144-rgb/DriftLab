# Руководство пользователя

1. Установите зависимости и запустите `python -m streamlit run app.py`.
2. На главной панели проверьте, есть ли сохранённые эксперименты.
3. Откройте «Лаборатория».
4. Выберите Covariate shift или Concept drift.
5. Настройте интенсивность, уровни, повторы, размеры выборок, шум и seed.
6. Оставьте выбранными все три стратегии для сопоставимого сравнения.
7. Нажмите «Запустить эксперимент». Полоса прогресса отражает фактически выполненные пары повтор/уровень.
8. Изучите главный график и агрегированную таблицу.
9. В «Сравнение и аналитика» выберите метрику и интенсивность, изучите распределения, границу решений и матрицу ошибок исходной модели.
10. Используйте кнопки экспорта для CSV, JSON и Markdown.
11. В «История» загрузите сохранённый результат. Модельные объекты не сохраняются в истории, поэтому диагностические графики границы решений доступны только в исходной сессии.

Демо-режим ограничивает число повторов/уровней и размеры данных, но выполняет реальные вычисления на синтетических данных.
