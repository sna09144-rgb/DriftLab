# Исследовательские заметки

Параметры обоих запусков: seed=42, 5 повторов, 5 уровней дрейфа (0…1), n_train=500, n_adapt=300, n_test=1000, шум меток 0.05, логистическая регрессия. Версии: Python 3.13, numpy 2.5, pandas 3.0, scikit-learn 1.9.

## Запуск 1 — covariate shift
- Вопрос: как сдвиг P(X) влияет на модель, обученную на исходных данных, и помогает ли адаптация?
- Гипотеза: исходная модель деградирует с ростом сдвига, стратегии с новыми данными восстанавливают качество.
- Результат (accuracy, среднее по 5 повторам):

| Интенсивность | Исходная | Переобучение | Объединение | Oracle |
|---|---|---|---|---|
| 0.00 | 0.745 | 0.745 | 0.747 | 0.830 |
| 0.25 | 0.674 | 0.658 | 0.670 | 0.808 |
| 0.50 | 0.598 | 0.533 | 0.586 | 0.780 |
| 0.75 | 0.542 | 0.605 | 0.534 | 0.772 |
| 1.00 | 0.439 | 0.657 | 0.500 | 0.791 |

- Различия (recent − baseline, парная разность, t-интервал 95%): при d=0.75 +0.063 [0.003; 0.123], при d=1.0 +0.218 [0.148; 0.288]; при d≤0.5 интервалы содержат 0.
- Вывод: исходная модель деградирует с 0.745 до 0.439. Переобучение выигрывает только при сильном сдвиге; при умеренном (d≈0.5) новая выборка из 300 объектов не помогает линейной модели, так как данные в смещённой области плохо описываются одной прямой. До oracle (≈0.79) ни одна стратегия не дотягивает.

## Запуск 2 — concept drift
- Результат (accuracy):

| Интенсивность | Исходная | Переобучение | Объединение | Oracle |
|---|---|---|---|---|
| 0.00 | 0.745 | 0.745 | 0.747 | 0.830 |
| 0.25 | 0.719 | 0.746 | 0.731 | 0.830 |
| 0.50 | 0.686 | 0.734 | 0.708 | 0.820 |
| 0.75 | 0.606 | 0.700 | 0.644 | 0.794 |
| 1.00 | 0.484 | 0.588 | 0.534 | 0.777 |

- Различия (recent − baseline): при d≥0.5 интервалы не содержат 0 (d=1.0: +0.104 [0.046; 0.162]).
- Вывод: исходная модель падает до уровня случайного угадывания (≈0.48); переобучение лучше всех, «объединение» занимает промежуточное место из-за устаревших данных в обучающей выборке.

## Ограничения интерпретации
- Всего 5 повторов, интервалы широкие; значимость с поправкой на множественные сравнения не проверялась.
- Синтетические двумерные данные, одна линейная модель; результаты зависят от выбранной нелинейности правила (коэффициент 1.5) и амплитуды сдвига.
- Стратегии различаются объёмом обучающих данных (500 / 300 / 800).
- Без нелинейности правила covariate shift почти не ухудшал модель (0.859→0.858): линейная модель была специфицирована верно.

## Следующие эксперименты
- Изменяемый фактор: размер адаптационной выборки (50…1000).
- Контролируемые параметры: тип дрейфа, интенсивность, шум, seed.
- Гипотеза: при малой адаптационной выборке «объединение» превосходит «переобучение».
- Критерий оценки: парная разность accuracy с t-интервалом 95%.
- Дополнительно: вторая модель (дерево решений) для проверки независимости выводов от модели.
