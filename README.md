# DriftLab — Interactive Machine Learning Drift Research Laboratory

Локальная исследовательская лаборатория для изучения влияния дрейфа данных на качество бинарной классификации и сравнения стратегий адаптации.

## Возможности

- Два сценария: covariate shift и concept drift.
- Три стратегии: исходная модель, переобучение на новых данных, объединение старых и новых данных.
- Логистическая регрессия в `Pipeline(StandardScaler, LogisticRegression)`.
- Accuracy, Precision, Recall, F1, Specificity, Balanced Accuracy, ROC-AUC и матрица ошибок.
- Повторные эксперименты, агрегаты, стандартное отклонение, t-интервалы 95%, парные разности стратегий и oracle-предел.
- Интерактивные Plotly-графики, SQLite-история, CSV/JSON/Markdown-экспорт.
- Русскоязычный интерфейс Streamlit.

## Требования и установка (Windows PowerShell)

Требуется Python 3.10 или новее (проверено на 3.13). Проверьте версию командой `python --version`.

```powershell
cd путь\к\DriftLab
python --version
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Если PowerShell блокирует активацию, можно запускать `.venv\Scripts\python.exe -m pip ...` без активации.

## Запуск

```powershell
python -m streamlit run app.py

Откройте URL, который Streamlit напечатает в терминале (обычно `http://localhost:8501`).

Для воспроизведения результатов статьи используйте фиксированный пресет: 6 уровней интенсивности от 0 до 1, 30 повторов, seed 20261910, размеры выборок 500/300/1000 и шум меток 0,05. Из корня проекта выполните:

```

## Первый эксперимент

В разделе «Лаборатория» выберите сценарий, интенсивность, число уровней и повторов, размеры выборок и seed. Нажмите «Запустить эксперимент». Запуск вычисляет модели и метрики; результаты сохраняются в `results/driftlab.sqlite3`.

Для короткой демонстрации включите демо-режим. Он уменьшает объём расчётов, но запускает настоящий конвейер на синтетических данных.

## Экспорт

После запуска доступны CSV детальных результатов и агрегатов, полный JSON и Markdown-отчёт. Детальные строки включают идентификаторы запуска, тип и интенсивность дрейфа, стратегию, seed, объёмы выборок и метрики.

## Научная постановка

- **Гипотеза:** при дрейфе исходная модель деградирует, а стратегии с новыми данными восстанавливают качество; конкретный выигрыш зависит от типа дрейфа и объёма данных.
- **Covariate shift:** второй признак смещается на 1.5·d, после чего метки генерируются фиксированным нелинейным правилом (линейная модель им не описывается точно).
- **Concept drift:** меняется ориентация правила генерации меток.
- **Исходная модель:** обучается только на исходной выборке.
- **Переобучение на новых данных:** использует только новую адаптационную выборку.
- **Объединение:** использует исходную и адаптационную выборки.

Внутри каждого повтора и уровня все стратегии проверяются на одном независимом тестовом наборе. Scaler обучается внутри Pipeline исключительно на данных соответствующей стратегии.

## Метрики

Положительный класс — `1`. Для Precision, Recall и F1 задано `zero_division=0`. ROC-AUC недоступна, если в тесте присутствует только один класс. Accuracy не отражает все ошибки при дисбалансе классов, поэтому также приводятся Recall, Specificity и Balanced Accuracy.

## Литература

- Shimodaira H. Improving predictive inference under covariate shift by weighting the log-likelihood function. J. Stat. Plan. Inference, 2000.
- Moreno-Torres J. G. et al. A unifying view on dataset shift in classification. Pattern Recognition, 2012.
- Gama J. et al. A survey on concept drift adaptation. ACM Computing Surveys, 2014.

## Воспроизводимость и ограничения

Параметры и seed сохраняются. Генерация теста отделена от обучения. Средние и стандартные отклонения считаются по повторам; 95%-е интервалы строятся по распределению Стьюдента (df = n−1) и при малом числе повторов получаются широкими. Парная разность стратегий и oracle-линия (предел точности) показаны в аналитике. Это синтетическая двумерная задача и одна модель, а не доказательство универсального превосходства стратегии или готовая система обнаружения всех видов дрейфа.

## Возможные проблемы

- `No module named streamlit`: активируйте нужное окружение и установите `requirements.txt`.
- Ошибка сборки пакета: проверьте версию Python и наличие совместимого wheel; не удаляйте системное окружение.
- Ошибка записи истории: проверьте права записи в `results/`.
- Долгий запуск: уменьшите повторы, размеры выборок или число уровней.
